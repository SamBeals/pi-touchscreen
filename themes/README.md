# Bundled themes

| ID | Mode | Notes |
|---|---|---|
| `sellmate-default` | light | Production default (white / lime retail) |
| `sellmate-light` | light | Spacious density variant |

Both ship **Source Sans 3** under `assets/fonts/` (SIL OFL).

Installed renter themes live under `/etc/sellmate/themes/<id>/`.
See [docs/THEMES.md](../docs/THEMES.md) and [docs/FIGMA.md](../docs/FIGMA.md).
